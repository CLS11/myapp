#  MyApp – Flutter Playground

This project is a versatile Flutter app created as a playground for learning, experimenting, and implementing various features of the Flutter framework. It includes practice on UI components, animations, state management, and app architecture concepts.

---

##  Purpose

-  Practice and experiment with Flutter widgets
-  Test integration of different packages and services
-  Explore new concepts including animations, layouts, and themes

---

##  Tech Stack

- **Flutter**
- **Dart**
- **Material Design**

---

##  Features

- Modular folder structure
- Responsive design
- Custom widget implementation
- Clean UI and navigation flow
